# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability or security invariant bypass in **DAS-LLM**, please report it responsibly directly to the maintainer rather than opening a public GitHub issue.

### Contact
* **Primary Contact**: Animesh Singh
* **Email**: [animeshs34@gmail.com](mailto:animeshs34@gmail.com)

Please include:
1. Description of the vulnerability or payload bypass.
2. Minimal reproducible Python script or YAML security manifest.
3. Expected vs. actual behavior.

We take security vulnerabilities seriously and will respond promptly to investigate and patch any confirmed issues.
